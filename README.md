# SalesNews.uz

SalesNews.uz - Telegram Premium, Stars, garant forumlar va TON NFT havolalari uchun yengil veb sahifa.

## Imkoniyatlar

- Telegram Premium va Stars paketlari
- SalesNews ekotizimi havolalari
- TON NFT va GetGems kolleksiyasi
- Adminlar sahifasi
- Silliq live notification

## Ishga tushirish

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Build natijasi `dist/` papkasiga chiqadi.
